# Yarışma ham verileri

Bu klasördeki dosyalar TEKNOFEST 2026 yarışma organizasyonu tarafından
sağlanmıştır ve yerinde değiştirilmez. Dosya ve sütun eşlemesi
`config/rules.yaml` içinde tanımlıdır.

| Dosya | İçerik |
|---|---|
| `sehirler_arasi_lojistik.xlsx` | Merkezler arası mesafe, araç tipine göre yolculuk süresi, hedef teslim günü (SLA) |
| `Araç_Kapasite_Maliyet_Saat.xlsx` | Araç tipleri, kapasite ve maliyetler |
| `Kiralık_Araclar.xlsx` | Zorunlu kiralık filo ve rotaları |
| `Ellecleme-kapasite.xlsx` | Merkez başına günlük elleçleme kapasitesi |
| `tir_kapasiteleri v2.xlsx` | Merkez başına günlük tır ziyaret kotası |
| `teknofest26_gelismis.xlsx` | Geçmiş talep verisi |
| `TALEP TAHMİNİ.xlsx` | Resmî talep tahmini şablonu |
| `TAŞIMA PLANI.xlsx` | Resmî taşıma planı şablonu |
